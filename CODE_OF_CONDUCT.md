# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be kind, patient and respectful.
- Welcome people of every background and experience level.
- Give and accept helpful feedback about the work, not the person.
- No harassment, insults or personal attacks.

If someone breaks these rules, report it privately to the maintainer through GitHub. Reports are kept confidential.
