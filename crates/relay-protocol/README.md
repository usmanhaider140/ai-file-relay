# ai-file-relay-protocol

Message types shared by the Chrome extension, the native messaging host and the hub in [AI File Relay](https://github.com/usmanhaider140/ai-file-relay). Every message is JSON with a `type` field. The same types are generated as TypeScript for the extension with ts-rs.

In code it is imported as `relay_protocol`.
