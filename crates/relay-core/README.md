# ai-file-relay-core

Transfer rules for [AI File Relay](https://github.com/usmanhaider140/ai-file-relay): allowed folders and safe path checks (no `..` or symlink escapes, sensitive folders always blocked), one-time file links, approvals, the transfer history, and the settings file.

Used by the `relay-mcp` command (crate `ai-file-relay`) and the desktop app. In code it is imported as `relay_core`.
